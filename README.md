# COMPARA — grocery receipts and price tracker

Built at the **NINF Winter Hackathon 2024** (FCT NOVA, February 2024).

Scan your supermarket receipts and see where each product is cheapest.

## Features
- Receipt parsers for Continente and Pingo Doce (`backend/receipt_parser/`).
- Product price history per store, with charts.
- Shopping cart that shows the cheapest store.
- Spending statistics.

Live demo: https://ninf-winter-hackathon24.vercel.app

## Stack
Next.js 14 · TypeScript · Prisma · Tailwind + Radix UI · Chart.js · Python (Flask, MongoDB)
